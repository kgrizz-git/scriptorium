# Deferred plans

Last reviewed: 2026-08-23

Plans that are **intentionally postponed** — not abandoned, not in progress.

- Keep a short header `Status: deferred` and a one-line reason + target milestone if known.
- Link from root [`to_do.md`](../../to_do.md) **Icebox** section (or keep in **Active** if resuming soon).
- When work starts: move back to `plans/` and set `Status: in-progress`.
- When cancelled instead: move to `plans/archive/superseded/` with `Status: abandoned`.
